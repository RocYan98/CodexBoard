# CodexBoard 1.0.0

统一发布 macOS arm64 与 Windows x64 安装包，两端包含同一套最新任务面板、Remote 和桥接逻辑。

- 新增 Windows NSIS 安装包，内置 Node、SQLite、Caddy、frpc、Web 和桥接；修复 Windows 路径、命名管道、权限、Codex 检测和启动问题。
- 修复 Remote 新对话第一次发送未提交、连接失败反复刷新，以及旧对话和大历史加载失败。
- 未加载会话使用独立的短发现超时，历史同步保留较长等待；结果未知的写操作不自动重复发送。
- 任务面板与 Remote 动态读取 Desktop 模型目录和有效缓存中的 Default 推荐档位；不会将全部模型与推理强度任意组合。
- Remote 使用 Desktop 活动时间和明确项目归属，修复旧目录、工作树任务漏显示及打开旧对话后排序变化。
- 修复移动 Web 首次登录导航、输入聚焦与键盘收起布局；改进附件与相册选择。网页是否直接进入相册仍由浏览器和系统控制。
- 更新中英文 README、Agent 安装说明及 Windows 技能包装器。

## 下载

- Apple Silicon / macOS 13+：`CodexBoard-1.0.0-macos-arm64.dmg`，配套 `.sha256`。
- Windows x64：`CodexBoard-1.0.0-windows-x64-setup.exe`，配套 `.sha256`。安装器按需下载 WebView2。
- macOS 自动更新：`.app.tar.gz`、`.sig` 和 `latest.json`。Windows 当前使用下载新版安装器升级。

退出旧 CodexBoard 后再安装；不要退出 Codex Desktop，不要删除应用数据目录。Windows 原测试版与正式版使用同一数据目录，应避免同时运行。

macOS 使用 ad-hoc 签名，未进行 Developer ID 公证；Windows 安装器尚无 Authenticode 签名。系统安全提示由用户在核对来源与校验值后处理，不要关闭系统保护。

Windows 先前安装验证环境为 Server 2022；1.0.0 的构建和自动化测试在 Windows CI 执行。Windows 11 实机、真实任务执行和手机软键盘体验未包含在本次自动化验收内。
